# 45 Exercícios Java — Estruturas Condicionais 🔀

Coleção de 45 exercícios práticos em Java para treinar estruturas condicionais: `if` simples, `if/else`, `if/else if` encadeado, operador ternário e combinações de condições com operadores lógicos (`&&`, `||`, `!`).

Repositório: [Milesdev275/45-Exercicios-Java](https://github.com/Milesdev275/45-Exercicios-Java) · Pasta dos exercícios: [`estruturascondicionais/`](https://github.com/Milesdev275/45-Exercicios-Java/tree/main/estruturascondicionais)

> Clique no número ou no nome de qualquer exercício abaixo para abrir o código-fonte direto no GitHub.

## 🛠️ Como executar

```bash
git clone https://github.com/Milesdev275/45-Exercicios-Java.git
cd 45-Exercicios-Java/estruturascondicionais
javac Execicios01.java
java flamingo.exercicios.estruturascondicionais.Execicios01
```

Basta trocar `Execicios01` pelo número do exercício que deseja rodar (os arquivos pertencem ao pacote `flamingo.exercicios.estruturascondicionais`).

> **Nota:** alguns arquivos (ex.: `Execicios01`, `Execicios06`, `Execicios09` e `Execicios012`) declaram `main` sem o modificador `public static`, o que impede a execução direta via `java` até que sejam ajustados para `public static void main`.
